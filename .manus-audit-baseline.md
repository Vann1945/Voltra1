# Voltra1 Baseline Audit

- Repository: `Vann1945/Voltra1`
- Branch: `manus/voltra1-overhaul`
- Baseline commit: `f14ba247fb5f6fe5f25b5642bc208e17c2f264b2`
- Framework: Next.js 15 + React 19 + TypeScript; Vercel serverless API handlers in `src/api-handlers` wired through the app entrypoint.
- Active media provider code: ImageKit direct browser upload for images and Cloudinary signed upload for add-on files.
- Initial verification: `npm install --ignore-scripts` failed during cleanup of a partial dependency tree (`ENOTEMPTY`); after moving the partial tree aside, `npm ci --ignore-scripts` completed far enough to run `npm run lint`.
- Initial lint result: blocked with 110 TypeScript errors across the nested `marketplace-ui-refresh` archive, including missing Vite/Manus runtime modules. Root `tsconfig.json` currently includes all `**/*.ts` and `**/*.tsx`, so the independent nested app is pulled into the active root typecheck.
- Production build was not reached in the chained baseline command because lint failed first.
